# Self-Huddle
**Status:** Public / Formalized  
**Category:** Self-Leadership / Tactical Practice

## Definition
A tactical internal pause to review state, signal, and pattern before reacting or deciding. The Self-Huddle is the interruption tool for autopilot and survival responses.

## Core Language
- "Call the self-huddle."
- "The self-huddle is the pause before running the next play."

## Function
Creates the necessary gap between trigger and response. Allows the Operator to assess the internal system before executing the next move.
